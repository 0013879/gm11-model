# gm11-model

改进型 GM(1,1) 灰色预测模型 —— 自主复现

基于河南 7·20 特大暴雨情景的模拟转移人口数据，对比**标准 GM(1,1)** 与**改进 GM(1,1)**（一阶缓冲算子 + 网格搜索优化）的拟合与预测精度。

## 模型结构

| 模块 | 说明 |
|------|------|
| 标准 GM(1,1) | AGO 累加生成 → 构造背景值矩阵 → 最小二乘估计参数 [a, b] → 求解白化方程 → IAGO 累减还原 |
| 一阶缓冲算子 | 加权平滑，削弱灾害数据的随机波动，保留长期趋势 |
| 网格搜索优化 | 在 α ∈ [0.10, 0.97] 内以步长 0.01 搜索最优缓冲系数，目标为训练集 MAPE 最小 |

## 文件说明

- `gm11_model.py` — 完整模型代码（单文件，可直接运行）
- `gm11_reproduction_result.png` — 运行生成的四联结果图表
- `gm11_model_results.json` — 模型参数与精度指标

## 运行方法

```bash
pip install numpy matplotlib
python gm11_model.py
```

运行后终端打印完整建模过程，图表与结果文件保存在当前目录。

## 技术要点

- 训练集 / 测试集划分：前 5 天训练，后 2 天验证
- 精度指标：MAPE、RMSE
- 模拟数据加入 3% 随机波动（seed=42），模拟真实灾害上报噪声
